ARK II — PRE-DEPLOYMENT AUDIT BUILD

MAJOR BUGS FIXED
1. Footer wordmark was excessively large and cropped by a fixed-height
   container. The footer is now structured, shorter and fully visible.
2. Navigation used mix-blend-mode: difference. On the orange footer this
   created blue/cyan text. The navbar now becomes a dark glass panel after
   scrolling and keeps the correct brand colours everywhere.
3. The studio ticker did not contain enough repeated content for wide
   screens. It now has two identical extra-wide groups and loops with no
   empty section.
4. Project cards linked to IDs that did not exist. They now open accessible
   case-study panels with Challenge, Approach and Outcome content.
5. Loader used a fixed timer and session storage. It now appears on every
   hard refresh, waits for the page and fonts, has a minimum duration,
   maximum failsafe, progress counter and discipline sequence.
6. App has a seven-second failsafe so loader or asset errors can never keep
   the website invisible.
7. Loader now immediately completes for reduced-motion users instead of
   displaying a hidden loader over invisible content.
8. Unconfigured email and Instagram fields are hidden instead of showing
   “coming soon” on the public website.
9. Select fields now have a visible custom arrow and sensible autocomplete.
10. Official Lenis CSS is imported; anchor offset accounts for the floating
    navigation.
11. Added vite.config.js and moved Vite/React plugin to devDependencies.
12. Added ESLint flat configuration so npm run lint has a real config.
13. Increased critical small-text sizes and added keyboard focus states.
14. Modal, mobile menu and loader support Escape/body-scroll handling.
15. Animations remain transform/opacity focused and respect reduced motion.

BEFORE DEPLOYMENT
1. Stop Vite with Ctrl + C.
2. Replace the project with this folder.
3. Run:
     npm install
     npm audit
     npm run lint
     npm run build
     npm run dev
