ARK II — FINAL DEPLOYMENT GUIDE

LOCAL VERIFICATION
npm install
npm audit
npm run lint
npm run build
npm run dev

VERCEL
- Import the GitHub repository.
- Framework preset: Vite.
- Build command: npm run build.
- Output directory: dist.
- Deploy.

NETLIFY
- Add a new site from Git.
- Build command: npm run build.
- Publish directory: dist.
- Deploy.

PUBLIC DETAILS
Update src/data/site.js before launch.
Unconfigured email and Instagram items are automatically hidden.

AFTER RECEIVING THE FINAL URL
- Add the canonical URL and og:url to index.html.
- Add the property to Google Search Console.
- Generate sitemap.xml using the permanent domain.
- Run Lighthouse on mobile and desktop.
- Check the social preview through the relevant platform debugger.

This build includes the complete Stage 5 production setup, the Stage 6
network animation, and the Stage 7 deployment audit/fixes.
